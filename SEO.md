# SEO strategy

## Positioning

A11y Handoff is a free, practical accessibility tool for people building digital products. Search pages should lead with the task a visitor wants to complete, then explain the WCAG or EAA context without promising legal compliance.

Primary search themes:

- accessibility checklist
- WCAG checklist
- website accessibility audit
- Figma accessibility plugin
- accessible UI components
- accessibility handoff

## Page and query map

| Page | Main search intent |
| --- | --- |
| `/` | accessibility handoff tool, accessibility checklist |
| `/audit` | free accessibility audit, WCAG URL checker |
| `/checklist` | WCAG accessibility checklist, AA and AAA checklist |
| `/components` | accessible UI components, accessibility design patterns |
| `/components/:slug` | accessible button, dialog, form, navigation, card, or toast |
| `/figma-plugin` | free Figma accessibility plugin |
| `/about` | what accessibility handoff means |

## Content priorities

1. Add focused component guides for tabs, menus, tables, carousels, and settings.
2. Add short practical guides for keyboard testing, focus order, text zoom, contrast, and accessible names.
3. Link each guide to the checklist, relevant component pages, and official WCAG references.
4. Publish release notes when the Figma plugin or audit capabilities materially improve.

## Launch checklist

1. ✅ Connect `a11yhandoff.com` and redirect the temporary DigitalOcean URL to it.
2. ✅ Verify the domain in Google Search Console.
3. ✅ Submit `https://a11yhandoff.com/sitemap.xml`.
4. ✅ Request indexing for the home page, audit, checklist, components, and plugin pages.
5. Test structured data with Google's Rich Results Test.
6. Add a 1200×630 social preview image before broad promotion.
7. ✅ Create crawlable `/ja/` and `/ko/` URL structures with reciprocal `hreflang` tags.
8. Publish the plugin in Figma Community and link back to the official plugin page.
9. Add practical long-form guides for accessibility handoff, focus order, contrast, accessible names, and mobile accessibility.

## Measurement

Review monthly:

- indexed pages and crawl errors
- impressions and clicks by page and query
- click-through rate for audit, checklist, and plugin results
- visits from component-guide searches
- completed URL audits and checklist interactions from organic traffic

Avoid keyword stuffing, duplicate translated pages, fabricated ratings, and claims of automatic WCAG or EAA compliance.
